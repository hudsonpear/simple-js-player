Simple JS Player - Examples

Six players, each set up a different way. Every example uses the same clip, so the only difference is the data-* tags. The clip is 10 seconds long.

1. Defaults

The smallest setup: a source and a title. Every other option keeps its default value.

2. Start at a set time

Starts at 5 seconds instead of 0:00. data-startTime also accepts m:ss, such as "0:05".

3. Compact, minimal

The simple layout puts everything on one row, with no skip buttons or speed menu. The duration is hidden and the controls stay hidden until play.

4. Custom colors

The mini layout with a brand color for the timeline, buttons and timer. Use hex, rgb() or any CSS color.

5. Keyboard and mouse extras

Skip 5 seconds back and 30 forward, double-click for fullscreen, and show the player's own right-click menu. Try the arrow keys after clicking the player.

6. Fixed volume, no memory

Starts at 40% volume. The viewer's volume choice is not remembered between visits, and the right-click menu is off. The controls fade quickly after the pointer leaves.
